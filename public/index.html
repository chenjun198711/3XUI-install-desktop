第二步：设置面板的账号和端口
这些是你以后登录 3X-UI 管理面板用的。不知道怎么填？直接用默认值也完全没问题。
密码至少 8 位，建议包含大小写字母和数字
💡 域名需先在 DNS 服务商处添加 A 记录、指向这台服务器的 IP（如不确定可留空，之后再绑）。填写后：① 完成页会用域名生成面板地址，比裸 IP 好记；② 安装时自动帮你校验域名解析是否生效；③ 之后可在面板「面板设置 → SSL 证书」里一键申请证书，升级为 https 加密访问，防止登录密码在网络传输中被窃听。不填域名完全不影响面板使用，IP + 端口就是完整地址。
GitHub 加速（ghproxy 镜像） 安装默认自动尝试多个下载源（直连 GitHub → ghfast → ghproxy 等），任意一个可用即成功；开启后跳过直连、优先镜像，适合直连被墙的 VPS
